# Citation

If you use `dseams-plumed` in published work, cite the d-SEAMS methods paper
alongside PLUMED. The repository's
[`CITATION.cff`](https://github.com/d-SEAMS/dseams-plumed/blob/main/CITATION.cff)
carries the software citation metadata for this release, and the
PLUMED-NEST record is
[plumID:26.018](https://www.plumed-nest.org/eggs/26/018/).

## d-SEAMS methods paper

Goswami, R.; Goswami, A.; Singh, J. K. d-SEAMS: Deferred Structural
Elucidation Analysis for Molecular Simulations. *J. Chem. Inf. Model.*
2020, 60, 2169-2177.
[10.1021/acs.jcim.0c00031](https://doi.org/10.1021/acs.jcim.0c00031)
([arXiv:1909.09830](https://arxiv.org/abs/1909.09830)).

