Upstream branch for PLUMED
==========================

The branch `dseams-smooth` is cut from PLUMED master
`1d41a5467f1ae6cedd2c4582ac3c58c830706a3e`. Its tip is
`6b74afaed038296f37fcc897ba92e4940c8d7f4d`.

It adds the module `src/dseams` (on by default) with the action
DSEAMS_SMOOTH_CHILL, a CHANGES entry in `CHANGES/v2.11.md`, and
`regtest/dseams/rt-smooth`. The smooth fraction does not link an
external library. The discrete CHILL+ and ring actions stay in this
repository, because they need seams-core.

`make -C regtest dseams` runs that test through `regtest/scripts/run`,
the same driver the top-level `make regtest` uses. The ideal ice Ic
frame prints 0.99544036 and the reference matches. A bundle of the
branch, which requires the master commit above, is
`dseams-plumed-v7-upstream.bundle`.
