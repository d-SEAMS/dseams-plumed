# Topology keys

Every oxygen atom carries a local topology key: its rooted bonded
neighbourhood on the mutual `K`-nearest-neighbour graph within `HOPS` bonds
(3 by default). `nclasses` reports the number of distinct keys in the frame,
whether or not a library is loaded. Point `LIBRARY` at one or more key
libraries generated by `seams fingerprint --emit-library` to count how many
molecules match known phases such as clathrate hydrate frameworks or
high-pressure ices.

## Build key libraries with `seams`

Generate key libraries from reference structures using `--graph knn`
(matching `DSEAMS_CAGES`'s mutual neighbour graph) and without
`--color-types` (uncoloured oxygen graphs). Note that `seams fingerprint`
defaults to `--hops 2`, whereas `DSEAMS_CAGES` defaults to `HOPS=3`, so pass
`--hops` explicitly:

```bash
seams fingerprint ref_ic.lammpstrj \
  --type 1 --graph knn --hops 3 --emit-library Ic > ic_h3.keys

seams fingerprint ref_ic.lammpstrj \
  --type 1 --graph knn --hops 2 --emit-library Ic > ic_h2.keys
```

You can also emit compatible key libraries from the Python
([PydSEAMSlib](https://github.com/d-SEAMS/PydSEAMSlib)) and Lua
([yodaStruct](https://github.com/d-SEAMS/yodaStruct)) front ends.

## Match libraries in PLUMED

Pass a single file or a comma-separated list of files built at different hop
counts to `LIBRARY`:

```text
UNITS LENGTH=A
LOAD FILE=./build/libdseams_plumed.so

ice: DSEAMS_CAGES ...
  ATOMS=1-512
  CUTOFF=3.5
  CANDIDATE=5.5
  K=4
  LENGTH_SCALE=1.0
  HOPS=3
  LIBRARY=ic_h3.keys,ic_h2.keys
...

PRINT ...
  ARG=ice.nice,ice.nclasses,ice.nnamed
  STRIDE=1
  FILE=TOPO
  FMT=%8.0f
...
```

When multiple files are supplied at different hop counts, `DSEAMS_CAGES`
checks each molecule against the deepest library first and falls back to
shallower libraries when needed. A molecule whose outer third-hop shell is
perturbed near an interface or defect still takes a name from its intact
inner shells.

| Component | Meaning |
| --- | --- |
| `nclasses` | Distinct local topology keys on the mutual graph at `HOPS` bonds. |
| `nnamed` | Molecules whose local key matches at least one file in `LIBRARY` (`0` when `LIBRARY` is unset). |

On a perfect 512-molecule cubic-diamond lattice matched against its own
3-hop and 2-hop libraries, every site shares one topology class and every
molecule is named:

```text
#! FIELDS time ice.nice ice.nclasses ice.nnamed
 0.000000      512        1      512
```

## Library constraints

`DSEAMS_CAGES` checks the loaded libraries at setup time:

- The deepest library in `LIBRARY` must match `HOPS`.
- Every file in `LIBRARY` must have a distinct hop count.
- All files in `LIBRARY` must agree in colouring.
- All libraries must come from the same graph method (`--graph knn`).
