#+TITLE: dseams-plumed
#+OPTIONS: toc:nil

The d-SEAMS topological ice score as a PLUMED action.

=DSEAMS_CAGES= takes a group of oxygen atoms and, every step, builds the
mutual and union four-nearest-neighbour graphs, the primitive six-membered
rings and the seeded cage assignment of d-SEAMS 2.0, optionally completed
over edge-sharing rings. It reports how many molecules sit in a hexagonal
or double-diamond cage, the largest connected cluster of them, the split
into ice Ic, ice Ih and mixed, and CHILL+ on the same frame for
comparison. The counts are integers without derivatives: they drive
=PRINT=, =COMMITTOR= basins and stopping conditions, not a bias.

#+begin_src plumed
LOAD FILE=libdseams_plumed.so
ice: DSEAMS_CAGES ATOMS=1-4096 CUTOFF=3.5 COMPLETE
PRINT ARG=ice.nice,ice.nmax,ice.chillice,ice.chillmax STRIDE=100 FILE=ICE
COMMITTOR ARG=ice.nmax STRIDE=100 BASIN_LL1=0 BASIN_UL1=20 BASIN_LL2=800 BASIN_UL2=100000
#+end_src

Lengths inside the engine are Angstrom; =LENGTH_SCALE= converts from the
PLUMED length unit (10 for the default nm, 1 after =UNITS LENGTH=A=).

* Build

#+begin_src bash
pixi install            # plumed, compilers, meson; seams-core comes as a wrap
pixi run build          # build/libdseams_plumed.so
pixi run test           # plumed driver over the mW cubic fixture
#+end_src

Or against an installed engine: =pkg-config seams-core= is enough, the
wrap is the fallback.

* Check against the engine

=tests/driver_check.py= converts a LAMMPS dump to xyz, runs =plumed driver=
with the module loaded, and compares =nice=, =nmax=, =chillice= and
=chillmax= per frame with the engine's =walk_compare= table:

#+begin_src bash
python tests/driver_check.py $(which plumed) build/libdseams_plumed.so \
    data/nucleation.lammpstrj results/walks/figshare-nucleation.txt
#+end_src

* Inside LAMMPS

=fix plumed= must come before any fix that computes the pressure
internally (=fix npt=, =fix press/berendsen=), or LAMMPS refuses the
input. A minimal mW run that logs the score every 500 steps and stops on
a committor basin:

#+begin_src lammps
fix pl  all plumed plumedfile plumed.dat outfile plumed.log
fix npt all npt temp 215 215 1000 iso 1 1 10000
#+end_src

with =plumed.dat= as above and =LENGTH_SCALE=1.0= after =UNITS LENGTH=A=
(LAMMPS =units real= is Angstrom).

* Topology keys

Every molecule carries a local topology key (its rooted bonded
neighbourhood on the mutual graph within =HOPS= bonds, three by default).
=nclasses= counts the distinct keys in the frame. With =LIBRARY= pointing
at a key library written by =seams fingerprint --emit-library LABEL= (or by
the Python and Lua front ends), =nnamed= counts the molecules whose key the
library holds: a polymorph-agnostic order parameter, a hydrate framework
or a high-pressure ice as easily as ice I.

#+begin_example
hyd: DSEAMS_CAGES ATOMS=1-2944 LIBRARY=sI_sII.keys HOPS=3
PRINT ARG=hyd.nnamed,hyd.nclasses STRIDE=500 FILE=HYDRATE
#+end_example
